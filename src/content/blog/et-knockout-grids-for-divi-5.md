Knockout grids are grid sections that use empty cells as a design element. Image blocks, text panels and colour areas sit against deliberate negative space, and the contrast between filled and empty is what makes them read as layered rather than as a table.

Elegant Themes released seven of them free for Divi 5. Here's how to import them and, more usefully, the rules that keep them looking right once you've replaced the content.

> **TL;DR:** Download the pack, import via **Divi > Divi Library > Import & Export > Import**, then add to a page with **Add From Library**. Replace **text before images**. Resize by duplicating or deleting existing rows and modules rather than rebuilding. Keep some cells empty — that's the whole point of the format.

## Importing and Placing

**Import:**

1. Unzip the download.
2. Go to **Divi > Divi Library**.
3. Click **Import & Export** at the top.
4. In the **Import & Export Layouts** modal, open the **Import** tab.
5. Click **Choose File**, pick a JSON, then **Import Divi Builder Layouts**.

**Place:**

1. Open a page in the **Visual Builder**.
2. Add a new **Section**.
3. Click **Add From Library** and choose a knockout grid section.

Import the "(All)" file if you want to browse all seven in the builder and decide by eye. Import individually if you already know which one you want and would rather keep the Library tidy.

## The Editing Order That Doesn't Break Things

**Text first, images second.** Replace headings, body copy, buttons, labels, captions, service details, property text, portfolio copy and CTAs. Only then swap the images, background photos, product visuals and screenshots.

The reason is that copy length changes the balance. A heading twice as long as the placeholder rewraps and eats the negative space the layout depends on. Judge your images against your real copy, not against Lorem Ipsum.

Work **one area at a time**. These sections balance imagery, typography, spacing and negative space against each other, and changing three things at once means you can't tell which change caused the problem.

**To resize:** duplicate or delete existing rows, columns, groups, image modules, text modules and buttons rather than building new ones from scratch. That preserves the grid structure and rhythm you're paying for.

## What to Adjust Where

| Goal | Path |
|---|---|
| Typography | Text or Heading module → **Design** → Font, Font Weight, Text Alignment, Text Color, Text Size, Letter Spacing, Line Height |
| Structure and visuals | Section / Row / Column / Group / Module → **Content** and **Design** → Background, Border Width, Border Color, Border Radius, Box Shadow, Sizing, Spacing, Position |
| Responsive | Divi's responsive controls for stacking, image height, crop position, spacing, text size, column order, button placement |

Before you start restyling, get your brand values into [Divi 5's Variable Manager](/blog/divi-5-global-variables-complete-guide/). Then restyling the pack is picking variables rather than typing hex codes into fourteen modules.

## Four Design Rules for Knockout Grids

**1. Route the eye deliberately.** Use the image blocks, text panels, empty space and colour areas to lead from the main visual to the key message to the CTA. If the path isn't obvious to you, it definitely isn't obvious to a visitor.

**2. Leave cells empty.** Especially with detailed or high-contrast photography. The empty cells aren't unfinished — they're the reason the filled ones have impact.

**3. Keep the text short.** Short headings, concise supporting copy, obvious CTAs. Knockout grids turn busy faster than almost any other layout format, and long copy is how it happens.

**4. Pick images with strong focal points.** Grid cells crop, split and squeeze images. A photo where the subject is centred and unambiguous survives that. A wide scene with detail spread across the frame does not.

The image cropping in particular is worth setting up properly — [Aspect Ratio and Object Fit](/blog/et-how-to-build-better-blog-portfolio-and-product-grids-with-as/) give you control over which part of each photo survives the crop, which matters a great deal when a cell is a narrow vertical slot.

## My Take: Import the Structure, Rebuild the Styling

Here's my one strong opinion: **treat a free layout pack as a structural reference and throw away everything else it gives you.**

I've built over 100 Divi sites and every layout pack I've ever imported has left the same trail: hardcoded colours, one-off font sizes, and border radii that match nothing else on the site. The layout looks great in isolation and slightly foreign everywhere it's placed.

The fix is a workflow, not a judgement call:

1. Import the section and keep the grid structure — the cell proportions and negative space are the genuinely valuable part, and the part that took a designer to get right.
2. Strip the styling. Reapply your own colour, typography, border and shadow presets.
3. Delete the imported Library item once you've adapted it, so nobody re-imports the unstyled version in six months.

Step 3 is the one everyone skips. An unadapted layout sitting in the Divi Library is a loaded gun pointed at your design system.

The structure is worth having, though. Getting the balance of filled and empty cells right by eye takes several attempts, and here it's already done. Same reasoning applies to the [free Divi 5 quote sections](/blog/et-large-quotes-for-divi-5/) — import for structure, restyle for consistency.

## Two Things That Will Catch You Out

**Swapping in images with different proportions changes the whole grid.** Image-heavy sections shift quickly when focal points, cropping or contrast change. After a photo swap, review the entire section rather than just the cell you touched — then adjust positioning, sizing, spacing or background settings.

**Tablet and phone shift noticeably** as columns stack. A knockout grid's negative space is a two-dimensional relationship, and stacking flattens it into one dimension. Check image cropping, text readability, spacing balance and tap-target size at every breakpoint before shipping.
