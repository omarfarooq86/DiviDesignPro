Elegant Themes just published a deep dive on [Divi 5's gradient variables](https://www.elegantthemes.com/blog/divi-resources/the-beauty-of-divi-5s-gradient-variables). You can now define gradient colors, angles, and opacity as reusable design tokens — the same way you handle solid colors in Divi 5's Global Variables system.

If you have ever recreated the same gradient across multiple modules, this saves serious time. Define it once, apply it anywhere with one click.

## Key Takeaways

- **Gradients are now variables** — define once, reuse everywhere
- **Linear, radial, and conic gradients** supported — full CSS spec
- **Opacity and angle controls** built into the Variable Manager
- **Works with Presets** — combine gradients with button and card styles
- **Update once, change everywhere** — edit the variable and all instances follow

## Practical Application

Pair gradient variables with Divi 5's Presets system. Define your brand gradient, create a button preset that uses it, and every button on your site shares the same style. Need to update? Edit the gradient variable — done.

For agencies, this means consistent brand gradients across every client site without manual per-module styling.
