Elegant Themes published a tutorial on [Divi 5's new text fill options](https://www.elegantthemes.com/blog/divi-resources/exploring-divi-5s-new-text-fill-options-create-text-gradients-and-image-masks). You can now apply gradients to text and mask text with background images — all inside the Visual Builder without custom CSS.

These effects were previously only possible with CSS background-clip tricks. Divi 5 brings them into the builder with a simple interface.

## Key Takeaways

- **Gradient text** — apply linear, radial, or conic gradients to any text
- **Image-masked text** — fill text with a background image pattern
- **No custom CSS required** — all handled in the text module settings
- **Works with all heading and text modules**
- **Pairs with Gradient Variables** for reusable gradient text styles

## How to Use

Open any text module in Divi 5, find the Text Fill settings, and choose your gradient or image fill. Combine this with the Gradient Variables system to reuse gradient text styles across your entire site.
