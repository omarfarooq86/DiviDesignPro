Elegant Themes continues their Flexbox mastery series with [Part 7: building flexible button, menu, and link rows](https://www.elegantthemes.com/blog/divi-resources/part-7-of-mastering-flexbox-building-flexible-button-menu-and-link-rows). This installment focuses on using Flexbox inside Divi 5 to create responsive button groups, navigation-like link rows, and evenly spaced CTA layouts.

## Key Takeaways

- **Flexbox for button groups** — evenly spaced, wrapping, responsive buttons
- **Menu-like link rows** — horizontal navigation without a menu module
- **Gap, justify-content, and align-items** controls in Divi 5
- **No custom CSS needed** — all Flexbox settings in Divi's UI
- **Responsive by default** — buttons wrap naturally on smaller screens

## How to Use

When building a row of buttons or links in Divi 5, open the row settings and use the Flex controls to set spacing, alignment, and wrapping behavior. Perfect for CTA sections, pricing page buttons, or footer link rows.
