Elegant Themes published a tutorial on [building better grids with Divi 5's aspect ratio controls](https://www.elegantthemes.com/blog/divi-resources/how-to-build-better-blog-portfolio-and-product-grids-with-aspect-ratio-in-divi-5). The aspect ratio setting ensures every image in a grid maintains the same proportions — no more mismatched card heights or uneven layouts.

## Key Takeaways

- **Aspect ratio locks image proportions** across grid items
- **Works with blog, portfolio, and WooCommerce grids**
- **No custom CSS needed** — set in Divi's image/column settings
- **Combined with the Loop Builder** for dynamic, perfectly aligned grids
- **Responsive-friendly** — aspect ratios hold across screen sizes

## How to Use

When building any image grid in Divi 5, set the aspect ratio in the image module settings or column background options. Choose 16:9 for landscape images, 1:1 for square, or 4:3 for standard photos. Every image in the grid conforms automatically.
