Elegant Themes released five large quote sections for Divi 5, free, available individually or as one combined download. Import takes about thirty seconds and they work on any existing page.

Here's how to get them in, plus the five design rules that decide whether a pull quote gets read or scrolled past.

> **TL;DR:** Five free Divi 5 quote sections, downloadable separately or as one combined JSON. Import via **Divi > Divi Library > Import & Export > Import**, then load onto any page from the Library. Keep quotes to one or two sentences, give them real whitespace, and always attribute.

## How to Import a Divi 5 Layout

Same process for these quote sections as for any Divi layout pack:

1. Download the JSON file — either one section or the combined file with all five.
2. In WordPress, go to **Divi > Divi Library**.
3. Click **Import & Export** (top right).
4. Choose the **Import** tab.
5. Upload the JSON and click **Import**.
6. The layout appears in your Divi Library.

To use it: open any page in the Visual Builder, choose **Load From Library**, and drop the section in. It's fully editable from there — colors, fonts, spacing, all of it.

The combined file is the one to grab. Import all five, delete the ones you don't like, keep the rest on hand. Importing five layouts takes exactly as long as importing one.

## Five Rules for Pull Quotes That Work

Free layouts get you a good starting point. These get you a good result.

### 1. Contrast enough to read as a break

A pull quote at 1.2× body size isn't a pull quote, it's a slightly awkward paragraph. Go big enough that a scanning reader's eye stops. That usually means at least double your body size.

### 2. Whitespace is the design

The most common mistake by a wide margin. A large quote crammed between two paragraphs with 20px of breathing room looks cheap no matter how nice the type is. Give it generous padding above and below — the emptiness *is* the emphasis.

### 3. Keep it short

One or two sentences. If your quote needs three lines at large size, it's body copy in a costume. Cut it or leave it inline.

### 4. Always attribute

Name and role, small, underneath. An unattributed quote at 48px reads as decoration. An attributed one reads as evidence. Small caps work beautifully here — [Divi 5's text styling controls](/blog/et-how-to-create-magazine-style-blog-posts-with-divi-5s-new-tex/) include All Small Caps, which is exactly the right register for a byline.

### 5. Match your site's typography

Don't let an imported layout smuggle in a font your site doesn't use. Swap the quote's typography to your own variables the moment you import it. Which is much easier if those values already live in [Divi 5's Variable Manager](/blog/divi-5-global-variables-complete-guide/).

## Save It as a Preset Immediately

Do this once and never style a quote again: after adjusting an imported quote section to match your brand, save it as an Element Preset.

Now every quote on the site is one click, and if you later change the accent color, you change it once. [Stacking and nesting presets](/blog/et-how-to-stack-nest-mix-and-match-presets-in-divi-5/) is the whole reason a free layout pack becomes reusable rather than a one-off.

The workflow: import → restyle to your variables → save as preset → delete the imported Library item. That last step keeps your Library from turning into a graveyard of half-edited layouts, which mine absolutely is.

## My Take: Import Layouts for Structure, Never for Style

Here's my one strong opinion: **free layout packs are worth using for their structure and worth stripping for their styling.**

I've built over 100 Divi sites, and the tell for a site built on unedited layout packs is instant. Not because the packs look bad — they're professionally made. It's because a page will have a hero in one font pairing, a quote section in another, and a testimonial row in a third, each internally beautiful and none of them related. The result looks like a well-designed magazine that got shuffled.

So: import the section for its *layout thinking* — where the quotation mark sits, how the attribution is positioned, what the padding ratio is. Then immediately replace every color, font and spacing value with your own. Takes four minutes and it's the difference between a site that looks designed and a site that looks assembled.

The corollary: **if you can't be bothered to restyle it, don't import it.** An unedited layout is a visible shortcut, and clients notice inconsistency long before they notice quality.

## Where Pull Quotes Actually Earn Their Space

A quick note on purpose, since "make it look nice" isn't a reason.

Pull quotes do three jobs: they break up long text so it looks readable, they let a scanning reader get the argument without reading the argument, and they give a page a quotable passage. That third one matters more than it used to — AI search results and featured snippets both favour clearly-delimited, self-contained statements.

So put your best sentence in the quote. Not a nice-sounding fragment — the actual claim you want repeated. One good pull quote per 1,000 words is about right. Three is a page that doesn't trust its own body copy.
