Elegant Themes published a complete guide on [Workspaces in Divi 5](https://www.elegantthemes.com/blog/divi-resources/everything-you-need-to-know-about-workspaces-in-divi-5). Workspaces save your builder layout — panel positions, toolbar settings, zoom level — and let you switch between configurations instantly.

If you juggle landing pages, blog layouts, and WooCommerce stores, workspaces save you from reconfiguring the builder each time.

## Key Takeaways

- **Save builder layout preferences** — toolbars, panels, zoom level
- **Create separate workspaces** for different project types
- **Switch in one click** from the builder toolbar
- **Great for agencies** managing multiple client projects
- **Settings persist across sessions**

## How to Use

Create a "Landing Page" workspace with the layer panel visible. Make a "Blog" workspace with the text editor focused. Switch between them depending on what you are building.
